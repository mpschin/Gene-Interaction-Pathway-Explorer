# Gene Interaction & Pathway Explorer

Streamlit MVP for exploring gene interactions and biological pathways via NCBI Entrez and Reactome.

## Setup

```bash
pip install -r requirements.txt
```

## Run

If `streamlit` is not on your PATH, use the Python module form:

```bash
python3 -m streamlit run app.py
```

Or use the helper script:

```bash
chmod +x run.sh
./run.sh
```

Then open the local URL shown in the terminal (usually http://localhost:8501).
